# 会话初始化 E2E 验证

- 2026 年 11 月 23 日。以 `c21adcb` 上的本地改动运行，CodyWebCore 为 `v0.47.0`。
- 使用生产构建、Chrome 1280px 和 820px 视口。本机回环地址连接临时 SQLite、两个合成 Git 仓库，以及 Codex App Server 和 Gemini ACP 协议测试进程。
- `pnpm verify` 通过，包含 288 个服务端测试、200 个网页测试及生产构建。

| 用例 | 结果 | 浏览器观察 |
| --- | --- | --- |
| E2E-001 | PASS | 错误密码被拒绝，正确密码进入工作空间，刷新后仍可访问。 |
| E2E-004 | PASS | 两个 Tab 直接打开同一需求会话，刷新及浏览器后退、前进恢复对应页面。 |
| E2E-007 | PASS | 慢回复开始前已显示用户消息，完成后页面仍显示一条。启动失败和重试另见 E2E-010。 |
| E2E-008 | PASS | 刷新后保留四条依次发送的消息及四条内容相同的独立回复。 |
| E2E-010 | PASS | 停止后显示取消，刷新后保持空闲。模拟启动失败后保留单个手动重试入口。 |
| E2E-011 | PASS | 两个 Tab 同步发送与回复。重启隔离服务后浏览器自动重连，已完成消息没有重复。 |
| E2E-012 | BLOCKED | 模拟 Codex 进程退出时页面显示失败，浏览器的实时连接仍在线。隔离协议测试进程不提供真实 HTTPS 回退与重试耗尽场景。 |
| E2E-015 | PASS（ACP 测试进程） | 首轮只传 `docs/context.md`、样本 JSON 等文档路径，约 225 KB 样本正文未进入请求。连续两次沉淀更新同一现有文件且只保留一次决策，新会话按路径读到该决策。 |
| Gemini 会话恢复 | PASS（ACP 测试进程） | 普通追问和刷新后只发送用户原文。完整重启服务后，同一原生会话沿用 SQLite 中的初始化标记，新原生会话收到独立的阅读指引。 |
| E2E-016 | PASS（相关路径） | Chrome 打开概览、需求列表、会话、知识库、Skills、设置与工具箱。在 820px 视口成功发送会话消息，两种宽度均无横向溢出。 |

正常路径未观察到浏览器运行时异常。输错密码、主动断开服务和模拟上游退出时观察到相应的 401、连接失败和 400。真实 Gemini 模型未参与此次验证。

临时浏览器、服务和协议测试进程已关闭。一次性数据库、仓库和 Worktree 随测试目录清理。此次改动未部署。
