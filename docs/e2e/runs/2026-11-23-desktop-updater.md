# CodyWork macOS 应用内更新验收

- 日期为 2026-11-23，北京时间。基线为 `010d838`，Core `v0.47.0`。
- 本机为 macOS Apple Silicon。使用临时签名密钥、独立应用标识、回环更新源、两套本地 CodyWork 与 SQLite、合成工作区和 Codex 测试进程。
- 真实更新文件由 Tauri 构建。测试用的回环 HTTP 覆盖只进入隔离构建，正常应用保留 HTTPS GitHub Releases 地址。
