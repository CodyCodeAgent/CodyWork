## 技术选择与范围

沿用成熟 Vue 3 + Vite + Cody Web Core，而非为外观迁移到另一套框架。Core 继续拥有消息、输入、审批、问题、事件归并与重连逻辑；没有新增消息缓存。原生 HTML dialog 提供顶层模态、键盘焦点约束与 Escape，Vue 负责状态；无需引入一整套组件库及第二套设计系统。新增独立 responsive.css 作为产品布局/设计 token 层，方便后续从历史样式逐步迁出。

- 深色导航 / 靛蓝强调色 / 浅色内容卡片 / 信息密度与字体层级统一。
- <=900px 顶部导航栏，工作台与会话完整抽屉，不再把会话导航隐藏且无替代入口。
- 桌面仍保留两栏/三栏及折叠偏好，移动临时状态不覆盖桌面偏好。
- 抽屉选择后收起，当前会话重复选择也收起；打开操作对话框前退出顶层抽屉。
- safe-area、100dvh、手机输入字体 16px、触控目标、模态滚动、卡片重排。
