## 结果与实现边界

标题左侧手柄支持 Pointer 拖动，6px 阈值避免误操作。拖动期间高亮目标并显示跟随预览，放手后只更新原布局的面板 ID 顺序；拖出取消、Escape、pointercancel、blur 及卸载清理均有逻辑覆盖。滚动边缘自动滚动。

键盘可在手柄按 Alt + 方向键，面板菜单有向前/向后移动；手机通过菜单排序并保留活动需求。放大时禁止排序。面板始终以 demandId 为 key，不重建会话或缓存 transcript；顺序经原 API 保存，继承 revision 冲突语义。本轮不修改数据库、后端或 Core。

`pnpm verify` 最终退出 0：263 后端 + 163 前端，共 426 项，类型检查、服务网络测试、生产构建通过，仅有原大 bundle 提示。单测覆盖指针阈值/提交一次/异源 pointer/取消/自动滚动/卸载、三个布局重排时 DOM 和草稿实例保持、保存携带原会话绑定，以及键盘边界。
