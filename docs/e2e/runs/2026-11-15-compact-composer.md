## 发现并修复的问题

1. 原收起逻辑移除整个 Composer；改为共享 Core 精简布局，隐藏设置而保留输入与操作。
2. 并行样式预留 25px，皮肤强制头像 36px；统一使用头像尺寸变量。首次实测仍只有 5px 间距，定位到更高优先级的 25px 分栏，修正后实测 12px。
3. 三列内长 placeholder 换成多行，导致空输入区过高；精简状态使用短提示。
4. 皮肤外框叠加和产品 textarea resize 覆盖紧凑布局；精简态不叠加皮肤外框，统一自动增高，去掉手动缩放柄。
5. Core package 已是 0.44.0，但 runtime 常量仍为 0.43.3，版本测试失败；同步常量与生成产物至 0.44.0。
